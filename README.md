# Website UMKM

Website UMKM dengan fitur katalog produk, cart, autentikasi user, dan halaman transaksi.

## Tech Stack

- PHP
- HTML / CSS
- JavaScript

## Fitur Utama

- **Produk** — `products_page.php`, `productDetail.php`, `product_upload.html`, `productControl.html`
- **Cart & Transaksi** — `cart.php`, `addCart.php`, `transactionDetail.php`, `transactionDetailCart.php`, `receipt.php`
- **Autentikasi** — `login.html`, `register.html`, `prosesLogin.php`, `register.php`, `logout.php`
- **Profil & Konten** — `account_profile.html`, `umkm_grow.html`, `creativity_booster.html`, `jobstreets.html`

## Menjalankan

Butuh PHP runtime dan database. Jalankan via XAMPP/Laragon atau `php -S localhost:8000`, lalu buka `index.php`.
